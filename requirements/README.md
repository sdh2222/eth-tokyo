# Requirements

Each pull request adds one file here and no product code in that first commit.

Name the file `NNN-short-slug.md`, with `NNN` as the next number.

```markdown
# NNN Short title

## One behavior

What a user or caller can do when this is done. One sentence.

## In scope

- The only change this PR may contain.

## Out of scope

- Nearby work this PR must not do.

## Acceptance

- [ ] An observable check. Command, request, or screen, plus the expected result.
```

A requirement is clear when a second person can run the acceptance checks without asking what you meant. If you need two behaviors, open two pull requests.
