## How to review

- Read a page, then comment on the line in question (in Notion or on the pull request). A comment never holds a decision: once the team settles it, the page text changes and the comment is resolved.
- A page goes Current when its Owner sets it after the team's review.
- Anything marked "(proposed)" or "(unverified)" needs a yes or a check before the page goes Current.
